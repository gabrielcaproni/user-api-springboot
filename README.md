# User API

API REST para cadastro de usuários desenvolvida com Spring Boot.

## Tecnologias
- Java 17
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- Gradle

## Funcionalidades
- Cadastro de usuário
- Integração com banco de dados
- Autenticação básica (Spring Security)

## Como executar
1. Configure o banco MySQL
2. Ajuste o `application.yml`
3. Execute:
```bash
./gradlew bootRun
